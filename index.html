00. Prepare o banco de dados

Abra seu cliente SQL (por exemplo, MySQL Workbench, DBeaver ou phpMyAdmin) e selecione um banco de dados de testes vazio. Execute os comandos na ordem abaixo. O simulador desta página funciona sem banco de dados.

Roteiro prático
CREATE TABLE cursos (
    id INT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL
);

CREATE TABLE alunos (
    id INT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    curso_id INT NULL,
    FOREIGN KEY (curso_id) REFERENCES cursos(id)
);

INSERT INTO cursos (id, nome) VALUES
    (1, 'Informática'),
    (2, 'Mecânica'),
    (3, 'Eletrônica');

INSERT INTO alunos (id, nome, curso_id) VALUES
    (1, 'Ana', 1),
    (2, 'Bruno', 2),
    (3, 'Carla', NULL),
    (4, 'Daniel', 1);

SELECT * FROM cursos ORDER BY id;
SELECT * FROM alunos ORDER BY id;

No MySQL ou MariaDB, você também pode criar um banco de testes com CREATE DATABASE laboratorio_joins; e selecioná-lo com USE laboratorio_joins;.

Passo 1 · Crie as tabelas (DDL)

CREATE TABLE cursos (
    id INT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL
);

CREATE TABLE alunos (
    id INT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    curso_id INT NULL,
    FOREIGN KEY (curso_id) REFERENCES cursos(id)
);

PRIMARY KEY identifica cada registro. FOREIGN KEY liga o aluno ao curso. Criamos cursos primeiro porque alunos depende dela. O campo curso_id aceita NULL para representar alunos sem curso.

Passo 2 · Insira os registros (DML)

INSERT INTO cursos (id, nome) VALUES
    (1, 'Informática'),
    (2, 'Mecânica'),
    (3, 'Eletrônica');

INSERT INTO alunos (id, nome, curso_id) VALUES
    (1, 'Ana', 1),
    (2, 'Bruno', 2),
    (3, 'Carla', NULL),
    (4, 'Daniel', 1);

Insira os cursos antes dos alunos para respeitar a chave estrangeira. Carla fica sem curso e Eletrônica fica sem alunos, de propósito.

Passo 3 · Confira os dados

SELECT * FROM cursos ORDER BY id;
SELECT * FROM alunos ORDER BY id;

Você deverá encontrar 3 cursos e 4 alunos, exatamente como nas tabelas da próxima seção.

Execute a criação e a inserção apenas uma vez em um banco vazio. Repetir os comandos pode gerar erros de tabela existente ou chave primária duplicada. Nenhum comando apaga dados existentes.

06. CROSS JOIN e SELF JOIN

CROSS JOIN

Combine todos os tamanhos com todas as cores de camisetas. Três tamanhos × três cores = nove combinações.

Preparar tabelas e dados do exemplo

SQL de preparação

CREATE TABLE tamanhos (
    id INT PRIMARY KEY,
    nome VARCHAR(10) NOT NULL
);
CREATE TABLE cores (
    id INT PRIMARY KEY,
    nome VARCHAR(30) NOT NULL
);
INSERT INTO tamanhos (id, nome) VALUES
    (1, 'P'), (2, 'M'), (3, 'G');
INSERT INTO cores (id, nome) VALUES
    (1, 'Azul'), (2, 'Verde'), (3, 'Vermelho');
SELECT t.nome, c.nome
FROM tamanhos t
CROSS JOIN cores c;

SELF JOIN

Uma tabela é relacionada consigo mesma por aliases. Não é uma palavra-chave SQL separada.

Preparar tabela e dados do exemplo

SQL de preparação

CREATE TABLE funcionarios (
    id INT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    gestor_id INT NULL,
    FOREIGN KEY (gestor_id) REFERENCES funcionarios(id)
);
INSERT INTO funcionarios (id, nome, gestor_id)
VALUES (1, 'Gerente', NULL);
INSERT INTO funcionarios (id, nome, gestor_id) VALUES
    (2, 'Ana', 1), (3, 'Bruno', 1);
SELECT f.nome, g.nome AS gestor
FROM funcionarios f
LEFT JOIN funcionarios g
ON f.gestor_id = g.id;

08. Atenção ao MySQL e MariaDB

Esses bancos não oferecem FULL OUTER JOIN diretamente. Combine LEFT JOIN com os registros sem correspondência do RIGHT JOIN usando UNION ALL.

SELECT a.nome AS aluno, c.nome AS curso
FROM alunos a
LEFT JOIN cursos c ON a.curso_id = c.id

UNION ALL

SELECT a.nome AS aluno, c.nome AS curso
FROM alunos a
RIGHT JOIN cursos c ON a.curso_id = c.id
WHERE a.id IS NULL;

O filtro evita repetir os pares já retornados pelo primeiro SELECT; UNION ALL preserva duplicatas legítimas.
